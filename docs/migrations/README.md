# Migration Guides

No major version has shipped yet, so there are no guides. When a release bumps the major version
(or makes breaking changes in 0.x), add the guide in the release-preparation pull request, not
afterwards:

1. Copy [TEMPLATE-major-version-migration.md](TEMPLATE-major-version-migration.md).
2. Fill in the breaking-change inventory, before/after samples and deprecation timeline.
3. Link the guide from the GitHub Release notes.
